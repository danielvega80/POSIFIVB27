# Pizarra nuevas normas · versión instalable

## Publicar en GitHub Pages
1. Crea un repositorio nuevo, por ejemplo `pizarra-nuevas-normas`. Si ya subiste la Pizarra K1, usa otro repositorio u otra carpeta para que no se pisen.
2. Sube todos estos archivos tal cual, sin cambiar nombres: `index.html`, `manifest.webmanifest`, `sw.js` y los iconos `.png`.
3. En el repositorio: Settings → Pages → Branch `main`, carpeta `/ (root)` → Save.
4. Espera un minuto y abre `https://TU-USUARIO.github.io/pizarra-nuevas-normas/`.

## Instalar en el móvil o la tablet
- **Android (Chrome):** menú ⋮ → «Instalar aplicación» o «Añadir a pantalla de inicio».
- **iPhone / iPad (Safari):** botón Compartir → «Añadir a pantalla de inicio».

Ábrela una vez con conexión. A partir de ahí funciona sin internet en el pabellón.

## Actualizar
Sube el nuevo `index.html` y cambia en `sw.js` la línea `pizarra-nuevas-normas-v1` por `v2`, `v3`… para que los móviles descarguen la versión nueva.

## Datos
Jugadas, plantillas, tiempos de saque y ajustes se guardan en cada dispositivo. Para pasarlos desde la pizarra de Claude o entre móviles, usa «Copiar código» y «Cargar código pegado».
